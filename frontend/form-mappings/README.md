# form-mappings

Generated by `cd frontend && npm run forms:inspect`.

* `<FORM_CODE>.json` — the mapping contract between a government artifact and the
  canonical SmartPR profile. For AcroForm artifacts every native field is listed;
  for artifacts with no native fields each entry carries a coordinate
  `placement` instead.
* `inventory/<FORM_CODE>.inventory.json` — the raw field inventory straight out of
  the PDF, so a reviewer can diff what the government file contains against what
  SmartPR mapped.
* `templates.manifest.json` — checksum, page count and native field count for each
  source file. Population fails closed if a source file no longer matches.

## Reviewing a mapping

`reviewed: false` with a `confidence` below `REVIEW_THRESHOLD` (0.85) means a
human has not confirmed the mapping. Set `reviewed: true` after checking it
against the real form — re-running the inspection preserves reviewed rows and
reports any field that disappeared from a new revision.

Coordinate placements additionally need visual validation: open
`/admin/form-mappings` and use **Open mapping preview**, which renders the real
artifact with every mapping boundary drawn on it.

Coordinates are bound to a specific template revision. A new agency revision must
be re-measured; mappings are never migrated automatically onto new bytes.
